Backend Retrieval Order

When the website receives a prompt, the retrieval engine should follow this sequence:

1. Determine topic
2. Identify applicable research question(s)
3. Retrieve canonical repository files
4. Retrieve evidence
5. Retrieve consensus and dissent
6. Check legal verification
7. Generate response
8. Cite repository version
9. Return confidence level

⸻

Canonical Principle

The navigation index is the routing layer for the entire Global Social Experiment.

Nothing should become part of the public website, academic article, book, conference presentation, or consulting methodology unless it can be traced back to a canonical repository source, associated research question(s), and supporting evidence.

This file is the master roadmap connecting every research domain, publication, and implementation artifact into a single version-controlled knowledge architecture.
